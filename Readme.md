# 🛒 NovaCart

NovaCart is a frontend e-commerce web application built using HTML, CSS, and JavaScript.

The project focuses on building a realistic shopping experience using vanilla JavaScript, DOM manipulation, event handling, form validation, and Local Storage.

## 🚀 Features

- 🏠 E-commerce homepage
- 🔎 Product search UI
- 🛍️ Product listing
- 🛒 Add products to cart
- ➕ Increase product quantity
- ➖ Decrease product quantity
- 🗑️ Remove products from cart
- 💾 Cart persistence using Local Storage
- 💰 Dynamic subtotal calculation
- 🚚 Delivery charge calculation
- 🧾 Multi-step checkout
- 📍 Delivery address validation
- 💳 Payment method selection
- 👀 Order review
- 🎉 Order placement confirmation
- 🔄 Cart count synchronization after page refresh

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Local Storage
